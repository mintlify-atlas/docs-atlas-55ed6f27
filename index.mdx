Mundo Escolar is a production-ready SQL Server 2022 relational database designed for school bookstores and stationery shops. It provides a fully normalized schema covering every core business operation — from managing product inventory and supplier purchases to processing customer sales, generating invoices, and recording payments — all backed by role-based access control and a complete audit trail.

## Script Files

The repository is organized into seven SQL script files that you run in sequence:

| File | Purpose |
|---|---|
| `Estructura.sql` | Creates the database, all tables, foreign keys, and unique constraints |
| `Inserciones.sql` | Seed data for lookup tables and initial records |
| `Procedimientos_Almacenados.sql` | Placeholder for stored procedures — not yet implemented |
| `Triggers.sql` | Placeholder for triggers — not yet implemented |
| `Reportes.sql` | Placeholder for reporting queries — not yet implemented |
| `Seguridad.sql` | Placeholder for SQL Server logins and role grants — not yet implemented |
| `Mantenimiento_Backups.sql` | Placeholder for backup and maintenance jobs — not yet implemented |

<Steps>
  <Step title="Set up SQL Server 2022">
    Ensure you have SQL Server 2022 running with the `C:\SQLData\` and `C:\SQLLog\` directories created, or update the file paths in `Estructura.sql` to match your environment.
  </Step>
  <Step title="Run Estructura.sql">
    Execute `Estructura.sql` in SSMS or `sqlcmd` to create the `MUNDO_ESCOLAR` database and all 24 tables.
  </Step>
  <Step title="Seed the database">
    Run `Inserciones.sql` to populate lookup tables with initial reference data.
  </Step>
  <Step title="Run the remaining script files">
    Execute `Procedimientos_Almacenados.sql`, `Triggers.sql`, `Reportes.sql`, `Seguridad.sql`, and `Mantenimiento_Backups.sql` in order. These files are currently unimplemented stubs — they establish the correct execution context and are ready for your custom logic.
  </Step>
</Steps>
